# 02 - Baseball Database Analysis

## Project Description
Using historical baseball data, perform operations such as aggregations, multi-table joins, and data filtering across multiple tables and metrics.

## Tasks Completed
- Investigated table structures and sample rows for `batting`, `teams`, `people`, and `pitching`
- Calculated the team with the highest average batter weight for a given year
- Identified the team with the largest total player payroll in a given year
- Determined the team with the lowest cost per win in 2010
- Found the priciest starting pitcher per game started
- Queried the batter with the highest hits per game in the 1990s
- Identified the pitcher with the lowest ERA for teams with home stadiums in Canada
