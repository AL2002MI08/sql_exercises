# 01 - Making a Database of Movies

## Project Description
Create a `films` table from scratch using PostgreSQL, insert and update data, alter table schemas, and enforce data integrity constraints.

## Tasks Completed
- Created `films` table with specified columns (`name`, `release_year`)
- Inserted movie records
- Filtered movies by release year
- Updated existing movie records
- Added new columns for supplementary data (`runtime`, `category`, `rating`, `box_office_earnings`)
- Backfilled missing data for newly added columns
- Added `UNIQUE` and `NOT NULL` constraints to ensure data integrity
